# 📚 Архів та дослідження роду Дівішеків (Divišek)

Цей репозиторій містить систематизовану базу знань, присвячену історії роду **Дівішеків**, їхній діяльності в сфері броварництва, а також пов'язаним підприємствам на території Волині та Поділля (Березне, Зіньків, Одеса, Проскурів тощо).

Матеріал зібрано на основі архівних метричних книг, міжвоєнних польських довідників, імперських реєстрів фабрик і заводів, періодичної преси та спеціалізованих видань (зокрема *Der Böhmische Bierbrauer*). 

База знань ведеться як сховище **Obsidian**, після чого автоматично збирається та експортується у форматі книги (PDF/HTML) за допомогою **Typst**.

## 🔬 Методологія та принципи

1. **Доказовість:** Кожна нотатка та зв'язок спираються на конкретне документне джерело.
2. **Ізоляція гіпотез:** Особи з однаковими ініціалами або незатвердженими родинними зв'язками зберігаються як окремі вузли до моменту прямого підтвердження.
3. **Хронологічна точність:** Події та володіння майном суворо прив'язані до часової шкали для уникнення злиття різних поколінь.

## 💡 Як працювати з матеріалами

Для використання цього проєкту залежно від ваших потреб потрібні різні інструменти:

* **Для перегляду та редагування (Obsidian):**
  Вам **достатньо лише додатку [Obsidian](https://obsidian.md/)**. Просто відкрийте папку `Obsidian_Divisek/` як сховище (vault). Усі нотатки, зв'язки між ними, джерела та зображення доступні у зручному форматі інтерактивної бази знань.

* **Для компіляції в PDF або HTML (Typst):**
  Якщо вам потрібно згенерувати фінальний документ у форматі книги або електронної сторінки, знадобиться встановлений **[Typst](https://typst.app/)**. Він зчитує Markdown-нотатки зі сховища та компілює їх у готові файли `Divisek.pdf` або `Divisek.html`.

### 🚀 Як скомпілювати нотатки локально

1. **Установити Typst** (докладніше на [typst.app](https://typst.app/)):
   ```bash
   # macOS (Homebrew)
   brew install typst

   # Cargo (Rust)
   cargo install --locked typst-cli
   ```
2. **Скомпілювати PDF-файл:**
   ```bash
   typst.exe watch --features html --format pdf Divisek.typ --root .        
   ```
3. **(Опціонально) Скомпілювати HTML-версію:**
   ```bash
   typst.exe watch --features html --format html Divisek.typ --root .  
   ```
