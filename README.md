# 📚 Архів та дослідження роду Дівішеків (Divišek)

Цей репозиторій містить систематизовану базі знань, присвячену історії роду Дівішеків, їхній діяльності в сфері броварництва, а також пов'язаним підприємствам на території Волині та Поділля (Березно, Зіньків, Одеса, Проскурів та ін.).

Матеріал зібрано на основі архівних метричних книг, міжвоєнних польських довідників, імперських реєстрів фабрик і заводів, періодичної преси та спеціалізованих видань (зокрема *Der Böhmische Bierbrauer*).

## 🔬 Методологія та принципи бази

1. **Доказовість:** Кожна нотатка та зв'язок спираються на конкретне документне джерело.
2. **Ізоляція гіпотез:** Особи з однаковими ініціалами або незатвердженими родинними зв'язками зберігаються як окремі нода-вузли до моменту прямого підтвердження.
3. **Хронологічна точність:** Події та володіння майном суворо прив'язані до часової шкали для уникнення злиття різних поколінь.
